# Wiz1 bug Fix

Q → Difficulty / bonuses → **Wiz1 bug Fix: OFF / ON**。
初期値OFF。次の8項目を一括で切り替える。個別切替はない。

- ACバグ修正
- 罠解除率バグ修正
- 倍打バグ修正
- 防御効果バグ修正
- 誤字修正（レブル・ポイゾン：アーチ）
- 支えの盾入手可
- 呪われアイテムもボルタック商店に並ぶ
- 全てのアイテムをボルタックが買い取る

変更時はバッテリーRAMを保存・保持してゲームをリセットする。
元ROMファイルは変更せず、エミュレーターの実行用PRGとセッション内コピーだけを変更する。
設定は `wiz1-bug-fix.txt` に保存。Wiz2/Wiz3には適用しない。
既知のWiz1コード配置に加えて全116変更箇所の元バイトが一致するROMだけ対応する。
パラメータ変更版は変更箇所が一致すれば利用可能。既に修正済みのROMは対象外。
通常SAV/JSONの識別は元ROMのまま。ステートにはON/OFFを記録し、異なる設定のステート読み込みは拒否する。
古いステートの設定はOFFとして扱う。設定を合わせてから読み込む。
OFFへ戻しても、プレイ中に購入・取得したアイテム等のセーブ内容は巻き戻さない。

## 採用元と実装

独自の戦闘・商店処理は作らず、ユーザー提供の以下のIPSを元ROMへ順に適用した差分116バイトを
`app/wiz1_bugfix_data.hpp` に記録。CPU/Mapperは既存binjnes（MIT）を利用し、上流コアは変更しない。

1. `reference/patch/fc/[110807] wiz1patch (2011-08)/wiz1patch.ips`
   - SHA256 `104de303bc184bd09208b19c8ad68a882efc2aeab077ec0c685aa40aa8372351`
   - 指定の最初の6項目が付属メモの内容と一致するため採用。
   - 同梱メモはハックロム総合スレpart8の892（901）氏とdigiverseを出典として紹介。
2. 単機能パッチ集13～26の `wizardry1_pg_fc_patch24_BoltacKAUYO.ips`
   - SHA256 `ce5dd6d77642ae1738ae8683d7c5dce987722783a269aa03a323d9c3761fb623`
3. 同 `wizardry1_pg_fc_patch25_BoltacURUYO.ips`
   - SHA256 `1f40ca6b19f4950c19c9305c4e037b49ef0f93c9e29540b1de32065cf5f1aabe`
   - 単機能パッチ集のメモではpart8の446（457）氏。指定の売買変更を再利用。

IPS資料の明示的なライセンス・再配布許諾は確認できていない。作者・出典の説明は同梱メモに基づく。
元資料は保持する。このローカル実装を第三者へ配布する際は、差分コードを含む権利条件の確認が必要。
IPSに新たなライセンスを付与したものではない。
AC修正は2011年版を採用しており、2009年版のマポーフィック追加補正は含まない。

## 検証

`python tools/verify_wiz1_bugfix.py` で全差分と3本のIPSの合成結果が一致すること、
通常版・パラメータ変更版の元バイト、AC処理のCPU実行結果を確認する。
`wiiz --bugfix-check ROM TEST_FOLDER` は既存binjnesで切替・SRAM保持・ステート設定照合・
音楽用コアを含む速度変更後のOFF復帰・元ROM非変更を検査する。Wiz2/3は適用拒否を検査。
罠解除・倍打・防御効果・誤字・盾ドロップ・商店売買の各ゲーム画面の全経路は未検証。
これらは既存IPSとの全差分一致を検証しているが、個別の実プレイ検証を代替しない。
