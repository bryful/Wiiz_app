# Wiiz

ファミコン版Wizardry Ⅰ・Ⅱ・Ⅲを、Windows／Androidで快適に遊ぶためのアプリです。
このアプリはファミコン版ウィザードリィのプレイヤーであり、ゲームの画像・BGM等のデータは含まれていません。実行には日本語ファミコン版のROMが必要です。
原作の映像・音声に加え、速度変更、探索済みマップ、ステート保存などを利用できます。

また、Androidで遊びやすいようにデュマピック・マロールはマップ指定に修正。
新規キャラクターの作成ボーナスを最大にしたり、次レベルに必要な経験値を補充したり、属性を変更したりする補助機能もあります。
詳細は設定メニューを参照してください。

現在は試作版です。作品やROMの版によって利用できない機能があります。

**ゲームROMは付属しません。ご自身で利用する権利のある対応ROM（`.nes`）を用意してください。**
開発環境のインストールやビルドは不要です。

## ダウンロードするもの

このリポジトリの「Code」→「Download ZIP」でダウンロードし、ZIP全体を展開してください。

| フォルダー | 内容・対象 |
|---|---|
| `Windows/` | Windows 10／11の64bit（x64）向け。`wiiz.exe`とDLL一式 |
| `Android/` | Android 6.0以降、64bit ARM（arm64-v8a）向けAPK |

Android APKはバージョン0.1.0の**配布用署名付きリリース版**です。32bit ARM／x86端末には対応しません。
Windows ARM端末での動作は未確認です。

## Windowsで遊ぶ

1. 展開した `Windows/roms/` に対応ROMの `.nes` ファイルを入れます。
2. `Windows/wiiz.exe` を起動します。隣のDLLは移動・削除しないでください。
3. 一覧から上下キーで作品を選び、XまたはEnterで開始します。

別の場所のROMを使う場合は、Qメニューの「Select ROM folder」でフォルダーを指定できます。
一覧にはフォルダー直下にある対応ROMだけを表示します。ZIPは事前に展開してください。

| 操作 | キーボード |
|---|---|
| 移動・項目選択 | 矢印キー |
| A・決定 | X / Enter |
| B・戻る | Z / Backspace |
| Select | A / Tab |
| Start | S / Space |
| 設定メニュー | Q |
| マップ | M |
| リセット | Esc |
| ステート保存（枠1～5） | F1～F5 |
| ステート読込（枠1～5） | Shift＋F1～F5 |

Qメニューは上下で選択、Xで決定、ZまたはQで戻ります。
「Game selection / rescan」でゲーム一覧へ、「Exit application」で終了します。
Escは現在のROMをリセットします。セーブ読込やゲーム一覧へ戻る操作ではありません。

## Androidで遊ぶ

1. `Android/Wiiz-0.1.0-arm64-v8a.apk` を端末へ転送して開きます。
2. 求められた場合は、APKを開いたファイルアプリ／ブラウザーの「この提供元のアプリを許可」を有効にしてインストールします。設定名は端末で異なります。
3. Wiizを起動し、標準のフォルダー選択で内部共有ストレージの `Documents` を選び、「このフォルダを使用」を許可します。既存の `Documents/Wiiz` を直接選んでも構いません。
4. 「ファイル」→「ROMを取り込む」から対応する `.nes` を選びます。選択した保存先の `Wiiz/Rom`（Wiizを直接選んだ場合はその中の `Rom`）へコピーされ、ゲームが起動します。
5. 次回からはROM一覧で作品を選べます。

### Google Play プロテクトでブロックされた場合

APKのインストール時に「デバイスを保護するため、アプリをブロックしました」「このデベロッパーのアプリはPlay プロテクトにスキャンされたことがありません」と表示される場合があります。これは開発元のアプリが未スキャンである旨の警告で、この表示だけで有害な動作が検出されたと断定することはできません。旧版をアンインストールしていても表示されます。

2026-10-25の端末確認では、警告の「詳細 ▼」を開くと「インストールする」が表示され、その操作でインストールできました。このリポジトリから取得したAPKであることを確認し、同じ未スキャンの警告の場合に限り、内容を確認してインストールを続けてください。「有害なアプリが検出された」など別の警告の場合は、この手順でそのまま進めず、正確な表示内容を確認してください。

インストール後は、次の手順でPlay プロテクトの検査を実行できます。

1. Playストア → プロフィール →「Play プロテクト」を開きます。
2. 右上の設定で「有害なアプリの検出精度を改善」をONにします。未知のアプリの情報がGoogleへ送信される設定です。
3. Play プロテクトの画面へ戻り、「スキャン」を実行します。

APKのコードや署名を変更するだけでは警告の解消を保証できません。スキャン後も、次回のインストールや更新で警告が出る可能性があります。Play プロテクトを無効にする必要はありません。今後の更新も現在の署名鍵を維持します。検査後もブロックが続く場合は、表示内容に応じて開発側でGoogleへの判定確認・再審査依頼を検討します。

詳しくは[Google Play プロテクトの公式説明](https://support.google.com/android/answer/2812853?hl=ja)を参照してください。

画面の十字キーとA/Bで操作します。SELはSelect、STAはStartです。
「設定」でメニュー、「マップ」でマップ、「SAVE 1／LOAD 1」で枠1の保存／読込を行います。
端末の縦横の向きに合わせて配置が変わります。
Androidの「リセット」はSAVを保存して同じROMを起動し直します。

保存フォルダーの変更は、ゲームを終了してアプリを開き直し、「ファイル」→「保存フォルダーを指定」で行います。
古い保存データは自動移動されません。同名で内容が異なるROMの取り込みは拒否します。

更新APKは同じ署名の場合に上書きインストールできます。署名が違う場合は更新できません。
再インストールする前には、必ず保存フォルダーをバックアップしてください。

以前のデバッグ署名版から今回のリリース版へは上書きできません。
アプリを終了して共有保存フォルダー全体をバックアップし、旧版をアンインストールしてから
リリース版をインストールしてください。初回起動で以前と同じ保存フォルダーを選び直します。
共有フォルダーのROM・セーブ・ステートは削除しないでください。

**2026-10-25の署名鍵交換前のリリース版も、新版へ上書きできません。**
同様に保存フォルダーをバックアップし、旧版をアンインストールしてから新版を導入してください。
バージョン表示は引き続き0.1.0です。配布ファイルの識別には [SHA256SUMS.txt](SHA256SUMS.txt) を使用できます。
今回のAPKの署名証明書SHA-256は次のとおりです（APKファイル自体のSHA-256とは異なります）。

```text
683401fed21653794b6bf89b6f50062e41fd63218e94c501f039c732287fa151
```

| 設定 | 左スティック押し込み | 左スティック押し込み |

## 設定メニューの詳細

WindowsはQ、Androidは画面の「設定」、ゲームパッドは左スティック押し込みで開きます。
メニュー表示中はゲームが一時停止します。上下で項目を選び、A・決定で実行します。
値を変更する項目は左右でも変更できます。「Back」またはB・戻るで一つ前へ戻り、Qでメニューを閉じます。
項目が画面に収まらない場合は、上下へ移動するとスクロールします。右上の数字は選択位置／項目数です。
画面では長い名前を短縮して表示するため、以下は画面の短い表記も併記しています。

### メニューの入口

| 表示項目 | 内容 |
|---|---|
| Resume game | メニューを閉じてゲームを再開 |
| State save / load | ステート5枠の保存・読込 |
| Display / speed | CRT表示とゲーム速度 |
| Save / startup | 通常セーブ形式と起動時のロゴ表示 |
| Game selection | 通常セーブを保存してゲーム一覧へ戻る |
| ROM folder（Select ROM folder） | WindowsのROM検索フォルダーを変更 |
| Exit application | 保存してアプリを終了 |
| Difficulty（Difficulty / bonuses） | 経験値・Gold・呪文・補助効果 |
| Roster order | タイトル画面で登録名簿の順序を変更 |

ゲーム一覧で開いた場合は、ゲーム中専用の項目を表示しません。
「Rescan ROMs」はROMフォルダーを再検索します。
AndroidのROM取り込み・共有保存フォルダーの指定は、画面の「ファイル」から行ってください。

### Display / speed：表示・速度

| 項目 | 選択肢・動作 |
|---|---|
| CRT | OFF／Mild（弱）／Standard（標準）。昔のブラウン管風の走査線・輪郭・発光を調整 |
| Speed | 1／2／4／8倍。音楽・SEと方向キーの連続入力は等速のまま、ゲーム進行を高速化 |

CRTはWindowsで初期値Mild、Androidで初期値OFFです。設定メニューやアプリ側の地図にはCRTをかけません。
速度の初期値は4倍です。原作の速さで遊ぶ場合は1倍を選んでください。
高速化に対応しないROMでは「this ROM: 1x」と表示し、1倍で動作します。
表示・速度の設定は次回起動にも引き継ぎます。

### Save / startup：保存・起動

| 項目 | 選択肢・動作 |
|---|---|
| Battery save | `.sav`（初期値）／`.json`。通常セーブの保存形式 |
| Skip logo（Skip manufacturer screen） | OFF（初期値）／ON。起動・リセット時のメーカー表示を省略 |
| Turbo File: connected | 対応ROMで表示。決定すると接続状態・保存先の案内を表示。転送操作は原作メニューで実行 |

ゲーム中に保存形式を変更すると、その時点の通常セーブを新しい形式で保存し、変更前のファイルは残します。
両形式がある場合は、選択中の形式を優先して読み込みます。
JSONを編集するときはアプリを終了してください。詳しい保存場所は後述の「セーブとバックアップ」を参照してください。
Skip logoの変更は次の起動・リセットから適用されます。対応するROMでのみ利用できます。
両設定とも次回起動に引き継ぎます。

### State save / load：途中状態の保存・読込

1. 上下でSlot 1～5を選びます。`saved` は保存済み、`empty` は空き枠です。
2. 左でSave（保存）、右でLoad（読込）を選びます。
3. A・決定で実行します。

保存済みの枠へSaveすると上書きします。Loadすると進行が保存時点へ戻ります。
WindowsではF1～F5で直接保存、Shift＋F1～F5で直接読込できます。
AndroidのSAVE 1／LOAD 1とゲームパッドの保存・読込ボタンは枠1を使用します。
通常セーブとは別の機能です。アプリ更新前には通常セーブもバックアップしてください。

### Difficulty：難易度・ボーナス

対応するⅠ・Ⅱ・Ⅲで使用できます。キャラクターの変更は通常セーブにも残るため、使用前のバックアップをおすすめします。

| 項目 | 内容 |
|---|---|
| Character | 対象となる登録名簿の1～20番を選択。名前を確認してから実行 |
| Gold amount | Goldの加算量を1,000／10,000／100,000／1,000,000から選択 |
| Next level EXP (inn) | 選択した1人の職業・現在経験値から、次の累積必要値まで加算。繰り返し実行可能。宿屋でレベルアップ |
| Add Gold | 選択した1人へGold amount分のGoldを加算 |
| Spell ALL | 選択した1人に魔術師・僧侶の全呪文を習得させる |
| MP FIXED AT 9 | 登録済み全員の両系統・全レベルの現在MPと最大MPを9に固定 |
| Always LOMILWA | ロミルワの照明効果を維持 |
| Always LATUMAPIC | ラツマピックの敵識別効果を維持。所持品の鑑定には適用しない |
| Always MAPORFIC | マポーフィックの保護効果を維持 |
| MAX CREATION BONUS | 次に新規作成するキャラクターのボーナスを、種族ごとに割り振れる最大値にする |
| Wiz1 bug Fix | OFF（初期値）／ON。対応するⅠの8項目をまとめて修正 |
| MIXED PARTY | 酒場で善悪混合パーティーを編成可能にする。初期値OFF。属性自体は変更しない |
| Set alignment: Good / Neutral / Evil | 選択した1人の属性を善・中立・悪へ変更 |

経験値・Gold・Spell ALLは、決定するたびに実行します。空き名簿には適用できません。
経験値の補充後は宿屋で休むと原作の成長処理が行われます。宿泊前でも実行するたびに加算後の経験値を読み直し、次の累積必要値まで加算します。戦士なら0→1000→1724→2972と複数回進められます。
経験値加算の項目下に「EXP EST. LV: 数値」で、現在経験値から推定されるレベルを表示します。加算すると表示も更新されます。実際の現在レベルへの反映は宿屋で行います。
これらの名簿操作は街や迷宮で移動を待っている状態で使用してください。戦闘・施設処理の途中は未検証です。

Spell ALLでは職業・レベル・現在MP・最大MPを変更しません。
MP固定でも未習得呪文の習得や沈黙・使用場所などの制限解除は行いません。
**MP固定をOFFにしても、変更済みのMPは元の値へ戻りません。**
常時効果をOFFにすると固定を解除し、残っている効果の解除は原作の処理に従います。

最大作成ボーナスは既存キャラクターには適用せず、割り振り途中のポイントも補充しません。
Ⅰ・Ⅱは人間62／エルフ60／ドワーフ60／ノーム59／ホビット58点、Ⅲは全種族60点です。

MP固定・常時効果3種・最大作成ボーナスは初期値がすべてOFFです。
ON/OFFはアプリ終了後も保持し、3作品で共通に使用します。ステートを読んでも現在のON/OFF設定を維持します。

### Wiz1 bug Fix：8項目を一括修正

Difficultyの「Wiz1 bug Fix: OFF / ON」で、次の8項目をまとめて切り替えます。個別切替はありません。

- ACバグ修正
- 罠解除率バグ修正
- 倍打バグ修正
- 防御効果バグ修正
- 誤字修正（レブル・ポイゾン：アーチ）
- 支えの盾を入手可能に変更
- 呪われアイテムもボルタック商店に並ぶように変更
- 全てのアイテムをボルタックが買い取るように変更

設定変更時は通常セーブを保存し、ゲームをリセットします。元のROMファイルは変更しません。
初期値OFFで、設定は次回起動にも引き継ぎます。確認済みのⅠでのみ表示し、Ⅱ・Ⅲには適用しません。
ステートのON/OFFと現在の設定が異なる場合は読み込めないため、設定を合わせてから読み込んでください。
OFFにしても、修正中に取得・売買したアイテムなどのセーブ内容は巻き戻しません。

### Wiz1の新規キャラクターの初期HP

**新規作成時の初期最大HPが15以下なら、最大HPと作成時の現在HPを15にします。**
全職業が対象です。16以上はそのままで、Wiz1 bug Fix・MAX CREATION BONUSのON/OFFとは独立して適用します。
ロードの初期HPが0になる原作の不具合への対策です。255になる場合は変更しません。
既存キャラクターのHP、戦闘中のHP減少、転職・ターボファイル転送・セーブ読込時のHPは変更しません。
既に最大HPが0になったキャラクターを自動修復する機能ではありません。

### Turbo File：ターボファイル

対応するⅠ・Ⅱ・Ⅲでは8KBのターボファイルを自動接続します。Save / startupに接続状態を表示します。
原作の「ターボファイルをつかう」から書き込み・読み込み・作品間のキャラクター転送を行ってください。
作品間で1つのカードを共有します。通常セーブとは別ファイルで、Windowsでは保存先直下の
`turbofile.tbf`、Androidでは選択した共有保存先の`Wiiz/turbofile.tbf`に保存します（Wiizを直接選んだ場合はその直下）。
ステート読込ではカード内容も保存時点へ戻ります。バックアップにはカードも含めてください。
同時起動などで他のアプリからカードが変更されていると、上書きせずエラーにします。
転送手順と確認済みの範囲は [ターボファイルの説明](Windows/docs/turbofile.md) を参照してください。

### Roster order：登録名簿の並べ替え

パーティーの前列・後列ではなく、登録名簿20枠の並び順を変更します。
原作の保存を済ませてタイトルへリセットし、ゲームを進めるボタンを押す前に設定を開いてください。

1. 「Roster order」を開き、上下で移動したいキャラクターを選びます。
2. A・決定でつかみます。選択位置に `*` が表示されます。
3. 上下で移動先を選びます。間のキャラクターは1枠ずつずれます。
4. もう一度A・決定で確定します。保存後、原作をタイトルへ起動し直します。

B・戻るで移動を取り消します。Qで閉じた場合も未確定の移動は破棄します。
確定前の通常セーブは自動バックアップします。
ステートを読み込むと名簿順もその保存時点へ戻ります。

### マップ表示

WindowsのM、Androidの「マップ」、ゲームパッドのRB／Rで、MPを消費せず探索済みの地図を開きます。
表示中はゲームを停止し、A・決定またはB・戻るで閉じます。
対応ROMでは原作のデュマピックやキャンプのマロールとも連動します。

## セーブとバックアップ

通常セーブは原作のセーブ領域を定期的に保存します。処理途中を丸ごと残すにはステートを使います。
ステートの読込は現在の進行を保存時点へ戻します。

| 環境 | 保存先 |
|---|---|
| Windows | エクスプローラーのアドレス欄に `%APPDATA%\Wiiz\Wiiz\` を入力。`saves/` が通常セーブ、`states/` がステート |
| Android | 選択した共有フォルダー内の `Wiiz/`。`Save/` が通常セーブ、`state/` がステート、`Rom/` がROM（Wiizを直接選んだ場合はその直下） |

**バックアップはアプリを終了してから保存フォルダー全体をコピーしてください。**
SAV使用時は探索記録の `.map.json` も一緒に保管してください。
ROM名を変えると通常セーブの名前も変わります。別ROM・別バージョン・別OS間のステート互換性は保証しません。
更新前にもバックアップを取ることをおすすめします。

## 困ったとき

- ROMが一覧に出ない：`.nes` を展開済みか、指定フォルダー直下にあるか確認してください。未対応の版は起動できません。ファイル名を変えても対応状況は変わりません。
- WindowsでDLL不足になる：`Windows/` 全体を展開し直してください。
- Androidでインストールできない：arm64端末か、提供元の許可、既存版との署名の違いを確認してください。
- Androidで保存先エラーになる：指定フォルダーへのアクセス権を確認し、必要なら保存フォルダーを指定し直してください。権限喪失時は別の場所へ自動保存しません。
- 音が出ない：端末の音量・出力先を確認してください。Windowsで音声出力を利用できない場合は無音で動作します。
