# ターボファイルでのキャラクター転送

原作のターボファイル（8KB）をエミュレートし、通常版・パラメータ変更版のFCⅠ・Ⅱ・Ⅲで共用する。検証済みプログラム配置のROMでは自動接続する。

## 操作

1. 転送元を起動し、町はずれ（Ⅰはキャッスル）→「ターボファイルをつかう」→「データをターボファイルにかきこむ」。原作の完了メッセージを確認する。
2. Q → Game selectionから転送先を起動する。切り替え時にターボファイルも保存する。
3. 転送先で同じ原作メニューを開き、「キャラクタのてんそう」（Ⅱでは「つうかのぎしき」も含む）を選ぶ。
4. 転送元の作品、キャラクター、原作の確認事項を選ぶ。Ⅱの子孫作成、Ⅲの能力調整などは原作どおりに処理する。

同じ作品のデータ全体を復元する場合は「データをターボファイルからよみこむ」。これはキャラクター単位の転送とは異なり、原作の確認画面に従って名簿全体を置き換える。
Q → Save / startupのTurbo File欄で接続状態と保存先を確認できる。

## 保存

Windowsでは `%APPDATA%\Wiiz\Wiiz\turbofile.tbf`。通常セーブの`saves`フォルダーと同じ親に置く。ROM別ではなく1個の共通カードを使用する。原作のファイル管理により、作品別のデータがカード内に記録される。
容量は8192バイト固定の生データ。独自ヘッダーは付けない。他エミュレーターとのファイル互換は未検証。Turbo File IIの4バンク切り替えや書き込み保護スイッチのUIは未対応。
変更は通常セーブと同じ自動保存、ゲーム切り替え、終了のタイミングで保存する。既存イメージを更新する前に`backups/turbofile/<時刻>.tbf`へ退避する。同時起動などでファイルが他から変更されていた場合は上書きせずエラーにする。
ステートにはカード内容と通信位置も含む。ステート読込後はカードも過去に戻り、次の保存時に共通ファイルへ反映される。旧ステートにターボファイル情報がなければ現在のカードを引き継ぐ。

## 既存実装とライセンス

[MAMEのnes_turbofile_device](https://github.com/mamedev/mame/blob/cd680acf012140761f9dee37dadd4c11a1207fbd/src/devices/bus/nes_ctrl/turbofile.cpp)の`read_exp` / `write`をCへ移植した。BSD-3-Clause、copyright-holders: kmg。原本・LICENSE・固定リビジョン・SHA256は`third_party/mame-turbofile/`に保持する。配布物のlicenses/MAME-TurboFile.txtとソースにも表示を保持する。
MAME全体やGPLのフレームワークは組み込まず、当該BSDファイルの通信処理だけを移植した。追加の実行時依存はない。Nestopia（GPL-2.0以降）とMesen2（GPL-3.0）も調査し、単独で取り込めるBSDのMAME実装を選んだ。
binjnesには任意の拡張端子コールバックを追加し、$4016書き込みと$4017のbit 2を接続する。CPU・PPU・APU・Mapper処理は既存コアを継続利用し、MMC1のⅠとMMC3のⅡ・Ⅲで実行する。キャラクター変換・転送先の登録・重複名チェック・データの検査は原作が実行する。
