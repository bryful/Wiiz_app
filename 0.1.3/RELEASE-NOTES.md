# Wiiz 0.1.3

通常マップから選択位置へ移動できず、決定時に機能メニューが開く不具合を修正しました。迷宮の探索中に加え、キャンプ本体・人物画面・呪文選択からも移動できます。キャンプは原作の保存・終了処理を経て移動し、MPは消費しません。
Androidの画面配置の再実行ループを修正し、移動できない場面では日本語で通知します。
Ⅰの移動後の再描画・地上帰還経路と、Ⅲの分割画面解除・セーブRAM有効化を修正しています。

Windows x64 Releaseと、現用の配布鍵で署名したAndroid arm64-v8a Release APKです。AndroidはversionCode 4、minSdk 23、targetSdk 35です。署名は0.1.2と一致します。

検証済み：WindowsでⅠ・Ⅱの通常マップ移動、Ⅲの通常版・パラメーター変更版の同階移動・直後の連続移動・階層移動・地上帰還・MP非消費・探索保存。ⅢはSDL入力で連続決定と、移動できない場面でマップを保持することも確認しました。

Android実機確認：Pixel 9aでⅠ（Wiz1 bug Fix ON）のキャンプからB10東15北9→東16北9、その後のダンジョン内で東15北9への連続移動をAボタンで確認しました。セーブ・ステートは検証後に退避時とSHA256一致で復元済みです。

未検証：Android実機でのⅡ・Ⅲ、全座標・全イベント。Wiz1の任意バグ修正パッチ由来データの再配布条件には従来の未確認事項があります（licenses/Wiz1-patches.txt参照）。

ROM・個人のセーブ／ステート・署名鍵・認証情報は含みません。
